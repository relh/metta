# Implement Deployment Dashboard

## Trigger

- Primary: "implementing deployment dashboard"

## Workflow

- Define dashboard scope first: services, key health metrics, and rollout/failure signals.
- Implement dashboard config with explicit data sources, filters, and stable panel naming.
- Add alerting thresholds or runbook links where operational action is expected.
- Validate dashboard correctness against recent deploy events before publishing.
