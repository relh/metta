# Document Pr Merged

## Trigger

- Primary: "documenting PR merged"

## Workflow

- Capture merged PR context: problem statement, final behavior, and notable tradeoffs.
- Summarize user-visible impact and any migration/operational implications.
- Link follow-up PRs, risks, or deferred work so branch history stays navigable.
- Format and verify the write-up against repository documentation conventions.
