# Test Failing Tests

## Trigger

- Primary: "testing failing tests"
- Variant: "testing see failing tests"
- Variant: "testing were failing"
- Variant: "testing failing figure out"
- Variant: "testing failing recent merges metta"

## Workflow

- Identify the exact behavior that needs validation.
- Run the smallest relevant test command first.
- If failures appear, isolate root cause before broad reruns.
- Report pass/fail status and any follow-up risks.
